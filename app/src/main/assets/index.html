GitHub Token — o singură dată
⚠️ Token-ul este stocat local în browser (localStorage). Nu este trimis nicăieri altundeva decât la api.github.com.
Cum generezi token-ul (gratuit, 2 minute):
1. Mergi la github.com/settings/tokens/new
2. Note: apk-forge · Expiration: No expiration
3. Bifează: repo (full) + workflow
4. Click Generate token → copiază → lipește sus

Token-ul îți permite să creezi repo-uri și să pornești GitHub Actions automat.
